# Personal Portfolio

## About

This project is a personal developer portfolio built from scratch using HTML, CSS, and JavaScript. The goal is to bring together what I've learned about web development and create a website that introduces me, presents my skills and projects, and provides a way to get in touch.

## Features

- **About Me:** A short introduction and profile photo.
- **Skills:** A section showcasing my technical skills.
- **Projects:** A showcase of my previous projects.
- **Hobbies:** A little about my interests outside programming.
- **Contact Form:** A form for visitors to enter their name, email, and message.
- **Theme Switcher:** A button that changes the website's appearance.
- **Responsive Design:** A layout designed to work on different screen sizes.

## Technologies

- HTML5 for the structure and content.
- CSS3 for styling, layout, and responsive design.
- JavaScript for DOM manipulation and interactive features.
- Git and GitHub for version control.

## How to Run

1. Clone the repository.
2. Open the `ex00` directory.
3. Open `index.html` in your browser.

No additional libraries or frameworks are required.

Through this project, I practiced combining HTML, CSS, and JavaScript into a complete website. I also worked with semantic HTML, responsive layouts, DOM manipulation, event handling, and Git version control.
